# Architecture

## The core idea: one engine, many businesses

A **single shared engine** (agents + skills) reads a **per-business config bundle** and runs the identical pipeline for any site. Adding a business = filling a config, not writing code.

## Why each choice

| Layer | Choice | Reason |
|---|---|---|
| UI + API | **Next.js** | One framework for dashboard + API routes; runs on every host |
| DB | **Postgres + Prisma** | Relational fits the lifecycle; Prisma = typed, portable |
| Long AI jobs + cron | **Inngest** (or Trigger.dev) | Research/writing takes minutes → **serverless functions time out**; a durable job runner solves this on any host |
| Agents | **Claude API** | The research/writing/grading brains |
| Auth | **NextAuth** | Multi-tenant logins |
| Results view | **Embedded Looker Studio** | Don't rebuild analytics — plug GSC+GA4 into a free, shareable report |
| Hosting | **Railway** (target) | Persistent workers + Postgres + cron in one; portable to Render / Vercel+Supabase |

## The pluggability layer (multi-tenant)

A **Business** row holds everything that differs between sites:
- `profileMd` + `brandVoice` — auto-generated by the intake agent
- `Connector[]` — GSC / GA4 / DataForSEO / Maps / CMS creds (encrypted)
- `Pillar[]` — content themes
- rules — `qualityThreshold`, `linksPerPage`, `cadencePerWeek`

Everything else in the DB is scoped by `businessId`. The engine never hardcodes a business.

### CMS Adapter pattern (the publishing magic)

One interface (`src/lib/cms/types.ts`): `publish() · update() · list() · healthCheck()`.
- `shopify.ts` implemented first (covers both casket sites).
- New platform = one new adapter file + a line in the registry. Nothing else changes.

## Secrets

- Global service keys → `.env` (Anthropic, DataForSEO, Google OAuth client, Maps, Firecrawl, Inngest).
- Per-business tokens (Shopify token, GSC refresh token) → **encrypted** in `Connector.configEnc` using `CONNECTOR_ENCRYPTION_KEY`. Never logged, never committed.

## Build vs buy (settled)

- **Buy/reuse:** analytics/results dashboard → Looker Studio (free). Rank data → DataForSEO. Your-site data → GSC (free).
- **Build:** the content *workflow* (idea→brief→research→write→grade→publish→improve). This doesn't exist off the shelf — it's the moat.

  lib/
    cms/                    adapter interface + per-platform impls
    grader/                 rubric + grading logic
    agents/                 research, writer, grader, improver
    connectors/             gsc, ga4, dataforseo, maps, firecrawl clients
    crypto/                 connector secret encryption
  components/               UI (pipeline board, scorecards, KPI tiles)
